# 패키지 제작실 AI 작성 안내서

이 문서를 AI(Claude, ChatGPT 등)에게 주면, 수업 주제에 맞는 **패키지 초안**을 제작실 엑셀 템플릿 형식으로 만들어 줍니다.
사람이 읽는 순서는 1~3번, AI가 따라야 할 규칙은 4번부터입니다.

## 1. 쓰는 순서

1. 제작실의 사건 표 아래 **엑셀 템플릿 받기**로 `패키지-입력-템플릿.xlsx`를 내려받습니다.
2. 이 안내서와 템플릿의 **주체목록·공간목록** 시트 내용을 AI에게 함께 주고, 만들고 싶은 주제를 말합니다.
3. AI가 준 표를 템플릿의 `사건`·`카테고리`·`관계` 시트에 붙여 넣고(예시 줄은 지워도 되고 두어도 됩니다), 제작실의 **엑셀 올리기**로 올립니다.
4. 올리기 전에 "사건 N개·카테고리 N개·관계 N개" 요약과 확인할 내용이 나옵니다. 확인하고 **추가하기**를 누르면 현재 초안에 더해집니다. 기존 내용은 바뀌지 않습니다.
5. 올린 뒤 사건 날짜와 내용을 훑어보고 고칩니다. AI가 쓴 내용은 반드시 교사가 사실 확인을 합니다.

AI에게 이렇게 요청하면 됩니다.

> 첨부한 「패키지 제작실 AI 작성 안내서」의 4~8번 규칙을 지켜서, **(주제)** 수업용 패키지 초안을 만들어 줘. 대상은 **(학교급·과목)**, 사건은 **(20~30)개** 정도로 해 줘. 결과는 `사건`, `카테고리`, `관계` 세 개의 표를 탭으로 구분된 텍스트(TSV)로 따로 보여 줘. 주체목록·공간목록에 없는 이름은 쓰지 말고, 필요한데 없는 것은 표 아래에 따로 적어 줘.

## 2. 데이터가 저장되는 구조

제작실의 데이터는 하나의 구글 시트(탭 12개)에 나뉘어 저장됩니다. 엑셀 템플릿은 이 구조를 사람이 쓰기 쉽게 **이름으로 연결하는 3개 시트**로 줄인 것이고, 올리면 제작실이 아래 탭에 맞게 ID를 붙여 저장합니다.

| 탭 | 한 줄의 뜻 | 주요 열 |
| --- | --- | --- |
| 패키지 | 수업 묶음 하나 | 패키지ID, 패키지명, 학교급, 과목, 설명 |
| 카테고리 | 사건을 묶는 분류 | 카테고리ID, 패키지ID, 카테고리명, 카테고리유형(시기·사건군·주제), 시작일, 종료일, 설명 |
| 사건 | 역사 사건 하나 | 사건ID, 날짜, 종료일, 사건명, 사건유형, 내용, 이미지, 중요도 |
| 관계 | 사건과 사건의 연결 | 관계ID, 패키지ID, 출발ID, 도착ID, 관계유형, 라벨, 설명, 출처 |
| 주체 | 국가·단체·인물 | 주체ID, 주체명, 구분, 원어명, 소개 |
| 공간 | 장소·지역 | 공간ID, 공간명, 공간유형, 시대별칭 |
| 사건_패키지 | 이 사건은 이 패키지에 들어간다 | 사건ID, 패키지ID |
| 사건_카테고리 | 이 사건은 이 카테고리에 속한다 | 사건ID, 카테고리ID |
| 사건_주체 | 이 사건에 이 주체가 이런 역할로 나온다 | 사건ID, 주체ID, 역할 |
| 사건_공간 | 이 사건은 이 공간과 관련 있다 | 사건ID, 공간ID |
| 카테고리_공간 / 주체_공간 | 카테고리·주체와 공간의 연결 | (엑셀 템플릿에서는 다루지 않음) |

핵심 개념은 다음과 같습니다.

- **사건**은 여러 카테고리에 동시에 속할 수 있습니다(예: 6·25 전쟁은 "냉전의 군사화"와 "1950년대"에 모두 속함).
- **주체와 공간은 미리 등록된 목록에서 고릅니다.** 엑셀에서 새로 만들지 않습니다.
- **관계**는 사건과 사건을 잇습니다. 같은 주제라는 이유만으로 인과관계를 만들지 않습니다.
- 사건 하나는 한 번만 만들고, 여러 패키지에서 다시 쓸 수 있습니다.

## 3. 엑셀 템플릿 시트 구성

`사건` 시트 (제목 줄 그대로 사용)

| 사건명 | 날짜 | 종료일 | 내용 | 중요도 | 유형 | 카테고리 | 행위주체 | 공간 | 이미지 주소 | 출처 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

`관계` 시트: `출발 사건명` · `도착 사건명` · `관계유형` · `설명` · `출처`

## 4. 작성 규칙 (AI가 지킬 것)

- 표의 **제목 줄을 바꾸지 않습니다.** 열 이름과 순서를 그대로 씁니다.
- 한 줄에 사건 하나입니다. 빈 줄, 합계 줄, 병합 셀을 만들지 않습니다.
- ID는 쓰지 않습니다. 모든 연결은 **이름**으로 합니다. 이름은 철자와 띄어쓰기까지 정확히 같아야 합니다.
- 한 칸에 여러 값은 **쉼표(,)** 로 구분합니다.
- 모르는 사실을 지어내지 않습니다. 날짜가 불확실하면 연도만 쓰거나 비우고, 표 아래에 "확인 필요"로 적습니다.
- 내용은 학생이 읽을 설명으로 **1~2문장**, 중학교·고등학교 수준의 쉬운 말로 씁니다. 사건명은 교과서 표기를 따릅니다.
- 사건 수는 요청받은 만큼만 만듭니다. 한 패키지는 20~30개 안팎을 기본으로 합니다(수업 50분 기준).

## 5. 칸별 형식

### 날짜·종료일·시작일

| 알고 있는 범위 | 쓰는 법 |
| --- | --- |
| 연도만 | `1950` |
| 연·월 | `1950-06` |
| 연·월·일 | `1950-06-25` |

- 하이픈(-)으로 구분한 **글자**로 씁니다. `1950.6.25`, `1950년 6월`, `50-06-25`는 올바르지 않습니다.
- 사건의 `종료일`은 기간이 있는 사건(전쟁, 협정 기간 등)만 씁니다. 한 시점의 사건은 비웁니다.
- 서기(양력)만 씁니다. 기원전·음력은 쓰지 않습니다.
- `날짜`는 사건 줄에서 필수입니다.

### 선택값 (글자가 정확히 같아야 합니다)

| 칸 | 쓸 수 있는 값 |
| --- | --- |
| 중요도 | `핵심·전환점` / `주요 사건` / `심화·보충` |
| 유형 | `사건` / `정책·조치` / `선언·보고서` / `배경·정세` / `시기·국면` |
| 카테고리 종류 | `시기` / `사건군` / `주제` |
| 행위주체 역할 | `주도자` / `참여자` / `피영향자` / `대립 상대방` / `중재자` / `지도자` / `실행자` / `작성자` / `창설자` / `관련자` |
| 관계유형 | `원인·계기` / `전환·변화` / `활동·실행` / `통합·편입` / `분열·개편` / `구조적 배경` |

- 중요도 분배 기준: `핵심·전환점`은 전체의 약 20%, `주요 사건`은 약 50%, 나머지는 `심화·보충`.
- 유형을 모르면 `사건`을 씁니다. 비워도 됩니다.

### 카테고리 칸 (사건 시트)

- `카테고리` 시트에 적은 **카테고리명**을 그대로 쓰고, 여러 개는 쉼표로 구분합니다. 예: `냉전의 군사화, 1950년대`
- 카테고리 시트에 없는 이름은 연결되지 않고 경고로 표시됩니다.
- 카테고리는 3~7개가 적당합니다. **시기**(연대 구분), **사건군**(같은 흐름의 사건 묶음), **주제**(정치·경제·사상 등)를 섞어 쓰되, 한 사건은 보통 1~3개에 속합니다.

### 행위주체 칸

- `이름(역할)` 형식으로, 여러 개는 쉼표로 구분합니다. 예: `미국(주도자), 소련(대립 상대방)`
- 이름은 템플릿 **주체목록** 시트에 있는 이름(또는 원어명)과 같아야 합니다. 목록에 없는 주체는 연결되지 않습니다.
- 역할을 모르면 `이름`만 씁니다. 사건당 주체는 1~4개면 충분합니다.

### 공간 칸

- 템플릿 **공간목록** 시트의 이름을 씁니다. 여러 개는 쉼표로 구분합니다. 목록에 없으면 연결되지 않습니다.

### 이미지 주소·출처

- 이미지는 `http://` 또는 `https://`로 시작하는 주소만 쓰고, 확실한 주소가 없으면 비웁니다. 임의의 주소를 만들어 내지 않습니다.
- 출처는 책·논문·사이트 이름이나 주소를 적습니다. 확인하지 못했으면 비웁니다.

### 관계 시트

- `출발 사건명`과 `도착 사건명`은 **사건 시트의 사건명과 똑같이** 씁니다.
- 방향이 있습니다. "출발 사건이 도착 사건의 원인·계기가 되었다"처럼 읽히도록 씁니다.
- `관계유형`은 반드시 고릅니다(비우면 그 줄은 올라가지 않습니다).
- 사건 수의 절반 정도(10~15개)면 충분합니다. 같은 두 사건을 같은 유형으로 두 번 쓰지 않습니다.

## 6. 올리기에서 일어나는 일

- 첫 칸이 `(예시)`로 시작하는 줄은 무시됩니다.
- 같은 사건명·날짜가 이미 패키지에 있으면 그 줄을 건너뜁니다. 같은 파일을 다시 올려도 중복되지 않습니다.
- 같은 이름의 카테고리가 이미 있으면 새로 만들지 않고 기존 것에 연결합니다.
- 잘못된 칸은 가능한 줄만 올리고, 무엇이 왜 빠졌는지 줄 번호와 함께 보여 줍니다.
- 올린 사건은 바로 업로드(게시)되지 않습니다. 제작실에서 내용을 확인한 뒤 평소처럼 업로드합니다.

## 8. 제출 전 확인 목록 (AI가 스스로 점검)

1. 세 표 모두 제목 줄이 템플릿과 같은가?
2. 모든 사건 줄에 사건명과 날짜가 있고, 날짜가 `연도` / `연-월` / `연-월-일` 형식인가?
3. 중요도·유형·종류·역할·관계유형이 위 선택값과 글자까지 같은가?
4. 사건의 카테고리 이름이 모두 `카테고리` 시트에 있는가?
5. 행위주체·공간이 모두 주체목록·공간목록에 있는 이름인가?
6. 관계의 출발·도착 사건명이 모두 `사건` 시트에 있고, 출발과 도착이 서로 다른가?
7. 확실하지 않은 사실을 지어내지 않았는가? 확인이 필요한 항목은 표 아래에 따로 적었는가?
