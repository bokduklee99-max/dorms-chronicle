# Dorms’ Chronicle

사건·인물·카테고리를 따라 역사를 탐색하는 정적 웹앱입니다. 기본 연표, Metro 노선도, 역사의 지층, 냉전 세계지도, Constellation을 제공합니다. 저장한 구성은 브라우저의 로컬 저장소에 보관되며, 다른 기기나 도메인으로 자동 이전되지 않습니다.

## 빌드와 배포

```sh
npm ci
npm test
npm run build:site
```

`dist/`가 완성된 배포 폴더입니다. 랜딩·탐색 설정·Metro와 기존 정적 페이지, 공개 데이터 사본·이미지·폰트를 함께 포함합니다. 소스·작업 기록·백업은 배포하지 않습니다. Vercel은 `vercel.json`에 따라 테스트 후 이 폴더를 빌드합니다. `index.html`과 `metro/`는 빌드로 생성되므로 Git에 보관하지 않습니다.

## Metro 메인 화면

Metro의 노선도·지층·세계지도는 1945년부터 시작합니다. 국공합작을 포함한 1945년 이전 기록은 저장된 데이터와 공개 시트 새로고침 모두에서 표시 대상에서 제외합니다. 시트 원본과 보관 사본은 수정하지 않습니다.

[Metro 열기](http://127.0.0.1:4187/metro/)는 기존의 굵고 둥근 노선·정류장·사진 카드 디자인을 유지합니다. 패키지의 카테고리를 선택하면 연결된 사건과 노선이 표시됩니다. 모든 노선은 왼쪽에서 오른쪽으로 갑니다. 위의 연도축에 사건을 연도별 날짜순으로 배치합니다. 사건이 많은 해는 가로로 넓어지고, 긴 노선도는 가로 스크롤로 탐색합니다. 열차 애니메이션은 제거했습니다.

한 사건이 여러 카테고리에 속하면 하나의 물리적 환승역을 여러 노선이 함께 통과합니다. 관계가 없는 노선은 해당 역을 우회하여 단순 교차가 환승으로 보이지 않게 합니다. 왼쪽 종점에는 카테고리 이름을 표시하며, 국가 칩은 연결 ID를 기준으로 관련 정류장만 밝게 남깁니다.

정류장을 누르면 원본 사진·관계망·관련 사건·재임자가 열립니다. 사진이 없는 기록에는 이미지를 임의로 넣지 않습니다. 상세 창은 첨부된 DHxWhy의 [Metro Map Gallery](https://21st.dev/@dhxwhy/components/metro-map-gallery) 컴포넌트를 확장해 재사용합니다. TypeScript·React·Tailwind v4를 사용하며, 기존 공개 시트와 파서를 공유합니다.

```sh
npm install
npm run dev
# http://127.0.0.1:5173/metro.html
npm run build
# 결과 metro/index.html, 기존 Python 서버에서 /metro/로 열림
npm test
```

빌드 결과는 루트의 시트 스크립트와 원본 이미지 파일을 함께 사용합니다. `metro/` 폴더만 따로 배포하지 말고 프로젝트 루트 자료와 함께 제공해야 합니다.

# 연표 수업 웹앱

구글 시트의 사건·국가·재임기간·카테고리 네 탭을 관계 ID로 연결해 읽는 정적 웹앱입니다. 이미지는 사건의 이미지 열에 저장합니다. 연표 탭에서 기본 연표, 국가별 동시 연표, 사건 관계망, 하루씩 공개를 전환합니다. 프레임워크나 패키지 설치 없이 실행합니다.

```sh
python3 -m http.server 4187 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:4187 을 여세요. 메인 주소는 Metro 화면으로 연결되며, 기존 지도·연표·게임은 `/classroom.html`에서 엽니다.

- 지도: 연도 이동, 주요 시점 재생, 지역 확대, 사건 선택
- 연표: 분류 필터, 사건 설명, 같은 시점 지도 이동
- 게임: 기준 사건을 놓고 새 사건이 들어갈 틈 선택, 즉시 채점, 정답 위치 누적, 5문제와 점수
- 데이터: 시트 사건 검색, 편집할 구글 시트 열기

## 시트 연결

[냉전 데이터 시트](https://docs.google.com/spreadsheets/d/1n3NFzBPos-c4QKu8r1UE3QwOngd0vK5Vf4pEXhnxGE0/edit#gid=201117001)는 **사건 / 국가 / 재임기간 / 카테고리** 네 탭으로 편집합니다. 사건 167개, 국가·지역·조직 75개, 재임 16구간, 카테고리 13개를 보존했습니다. 다대다 연결표 두 개와 앱 출력용 `web_feed`만 숨겨 두었습니다. 출처·인용·원본 URL·수집 기록·중복 보관·빈 확장 탭은 제거했습니다. `web_feed`만 기존 주소로 웹에 게시하며, 수식은 [docs/web-feed.formula.txt](docs/web-feed.formula.txt)에 보관했습니다.

`sheet-config.js`의 공개 CSV를 최초 로딩, 새로고침 버튼, 화면을 보고 있는 동안 1분 간격으로 읽습니다. Google의 재게시 지연 때문에 편집이 몇 분 뒤 반영될 수 있습니다. ID·관계·날짜 검증을 통과한 묶음만 적용하며, 실패하거나 사건 목록이 비면 마지막 정상 데이터를 유지하고 화면에 알립니다. `sheet-snapshot.js`는 최초 로딩·장애 시 사용할 167개 사건의 사본입니다. 비밀키나 편집 권한은 HTML에 넣지 않았습니다.

사건과 국가·카테고리는 숨김 연결표의 ID로 연결하고, 사건 탭에는 연결된 이름을 수식으로 표시합니다. 재임기간의 국가ID는 국가 탭을 참조합니다. 원본 지도자 표기는 재임이나 실제 참여와 구별합니다. 장소·역사 경계 데이터는 없으며 현재 지도는 아래에 설명한 예시입니다.

2026-11-17에 등록한 미국·소련 지도자 14명의 재임 16구간을 보존했습니다. 미국 대통령, 소련 공산당 제1서기·서기장, 소련 대통령을 구별합니다. 브레즈네프의 직위 명칭 변경과 고르바초프의 겸직은 별도 재임 행입니다. 흐루쇼프의 시작은 `1953-09`로 보존했으며 교체일에는 시각 정보 없이 한 명으로 단정하지 않습니다. 원본 사건의 제목·날짜·설명·초안 상태를 유지했습니다.

## 연표의 네 가지 화면

- **기본 연표:** 날짜 순서와 원문·사진을 함께 읽습니다.
- **국가별 동시 연표:** 같은 연도 행에서 각국 사건과 재임자를 비교합니다. 국가 연결과 원본 지도자 태그를 버튼으로 구별합니다. 167개 사건 모두 국가를 연결했으며 국가 관계는 505건입니다. 동서독·남북베트남·정부 수립 이전 지역을 구별하고 당시 조약 서명국을 포함했습니다. 새로 추가하는 사건에 국가가 없으면 미연결 열에 남깁니다.
- **사건 관계망:** 같은 주제 연결을 따라 중심 사건을 바꿉니다. 한 번에 가까운 이웃 6개까지 표시합니다. 같은 주제라는 이유로 인과관계를 만들지 않습니다. 기존에 입력된 인과관계는 없으며 별도의 빈 입력 탭은 제거했습니다.
- **하루씩 공개:** 일자가 확인된 사건만 같은 날끼리 묶습니다. 선택 시점 또는 첫 기록부터 시작해 하루씩 열거나 다음 기록까지 이동합니다. 열린 날짜 이후의 사건은 공개하지 않습니다. 원문에는 이후 상황이 담길 수 있어 별도 버튼으로 엽니다. 예측은 이 브라우저에 저장하며 시트로 전송하지 않습니다.

줄 세우기는 사건 탭의 `검토상태=verified`, `게임출제=TRUE`, `날짜유형=stated`인 사건을 사용합니다. 부분 날짜의 가능한 범위가 겹치거나 같은 날짜인 사건끼리는 비교하지 않습니다. 기준 사건 1개와 문제 5개를 만들 수 없으면 시트에서 출제 사건을 고르는 안내를 보여줍니다. 이관된 167개 사건은 전부 초안이므로 아직 출제하지 않습니다.

노션 사진 20장은 `assets/notion-images/`에 보존했고, 사건 탭의 이미지 열에서 읽습니다. 한 사건에 사진이 여러 장이면 셀 안에서 주소를 줄바꿈으로 구별하며 위에서 아래 순서로 표시합니다. 별도 사진 탭은 없습니다. `sheet-config.js`에서 기존 이미지 URL과 파일을 대응하며 일반 Drive 보기 링크는 원본 링크로 표시합니다. 사진 파일과 기존 라이선스 파일은 유지했습니다.

## 목업의 범위

시트로 이관한 노션 사건명·본문·부분 날짜를 사용합니다. 빠진 설명·장소·재임을 임의로 채우지 않습니다. 원본 노션에는 쓰지 않습니다. 게임은 오답도 정답 위치에 놓으며, 맞힌 문제마다 10점씩 총 50점입니다. 조별 운영과 결과 저장은 연결하지 않았습니다.

지도는 **현대 국경을 사용한 냉전 진영의 단순화된 예시**입니다. 시기별 역사 국경 데이터가 아닙니다. 독일은 동서 분단을 빗금으로, 소련은 같은 색의 영역 묶음으로 표현했습니다. 1991년에 소련 영역이 독립국으로 나뉘는 예시를 볼 수 있습니다. 동맹 관계도 국가별 변화를 모두 반영하지 않습니다. 실제 수업용 배포 전에는 역사 국경과 진영, 사건 내용을 검증해야 합니다.

편집과 공동 작업은 구글 시트에서 합니다. 앱에서 시트로 쓰기, 로그인, 노션 변경 자동 가져오기는 연결하지 않았습니다.

## 역사의 지층 탭

선택한 시기·주제의 사건은 연도별 세로 연표로 표시합니다. 연도 바로가기 버튼으로 해당 연도로 이동하며, 날짜·제목·원문 요약을 누르면 기존 사건 상세 창이 열립니다. 원문의 연도·월 단위 날짜는 그대로 유지합니다.

`/metro/?view=strata`에서 1945년 이후 사건을 시작 연도와 원본의 직접 주제 분류로 집계합니다. 1년·5년 단위, 주제별 칸 선택, 전체 주제의 세로 단면, 화살표 키 이동을 지원합니다. 칸에는 실제 기록 수를 표시하고 전체 칸의 공통 최댓값으로 진하기를 계산합니다. 사건이 여러 주제에 걸치면 각 행에 포함되지만 전체 주제의 사건 목록에서는 중복을 제거합니다. 사진·관계망 상세는 Metro와 공유하고, 다른 Metro 시기의 사건도 열 수 있습니다. 날짜 미상인 월·일을 새로 만들지 않으며, 빈 칸은 수록 기록이 없다는 뜻입니다.

## 냉전 세계지도 탭

`/metro/?view=world`에서 1945~1991년의 주요 동맹·지원 관계를 연말 기준으로 탐색합니다. [World Map / Manu Arora](https://21st.dev/@manuarora700/components/world-map)의 점묘 지도와 곡선 애니메이션 구성을 참고해, 기존 Natural Earth 윤곽과 SVG·CSS로 구현했습니다. 새 패키지나 외부 지도 서비스는 사용하지 않습니다. 국경은 표시하지 않으며, 현대 해안선 위 대표 좌표를 사용합니다.

파랑은 미국, 적갈색은 소련이며 실선은 동맹, 점선은 지원·개입입니다. 18개 국가와 17개 주요 관계를 선별했습니다. 관계별 기간·내용·출처는 `src/world-map-model.ts`와 선택 국가의 관계 카드에서 확인합니다. 미국의 아프간 저항 세력 지원과 소련의 아프간 정부 지원은 대상을 구별합니다. 1960년 중국의 기술지원 선 종료는 전문가 철수를 뜻하며 조약 만료가 아닙니다. 동독은 통일된 1990년 말에, 소련은 소멸한 1991년 말에 지도에서 제외합니다. 등록된 선이 없는 국가는 비동맹이나 중립이라는 뜻이 아닙니다. 지도는 모든 동맹·지원국을 포괄하지 않습니다.

연도 조절은 범위 막대·방향키·이전/다음 버튼·주요 연도 버튼으로 가능합니다. 국가 선택은 지도 점과 아래 국가 버튼을 함께 지원합니다. 선택 국가의 사건은 기존 시트의 국가 ID로 연결하며 선택 연도 이후 사건은 표시하지 않습니다. 국가 미선택 시 해당 연도의 사건을 보여줍니다. 사건을 누르면 기존 상세 창을 공유합니다. 동맹·지원 관계는 시트의 사건 공동 참여로 추론하지 않고 별도 표본 자료에서 읽습니다. 시트를 편집해도 관계선은 자동 생성되지 않습니다.
