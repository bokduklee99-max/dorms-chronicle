## 패키지

[패키지 탭](https://docs.google.com/spreadsheets/d/1n3NFzBPos-c4QKu8r1UE3QwOngd0vK5Vf4pEXhnxGE0/edit#gid=1965822688)은 `패키지ID · 패키지명 · 학교급 · 과목 · 설명` 순서다. 패키지ID는 고유 키이며 중복 입력을 막는다. 헤더는 첫 행에 고정하고 데이터 행은 비워 두었다. 현재는 패키지 정보를 등록하는 표이며 사건 연결과 앱 공개 출력에는 아직 포함하지 않는다.

## 관계

```text
사건 ↔ 국가 ← 재임기간
사건 ↔ 카테고리 → 상위 카테고리
사건.이미지 = 사진 주소
```

- 사건ID·국가ID·카테고리ID·재임ID는 각 테이블의 기본 키다. 이름·정렬이 바뀌어도 ID는 바꾸지 않는다.
- 재임기간의 국가ID는 국가 탭을 참조한다. 한 사람이 겸직하거나 재취임하면 재임 행을 별도로 만든다. 인물·직위의 중복 식별 정보는 같은 ID끼리 내용이 일치하는지 검사한다.
- 카테고리의 상위카테고리ID는 같은 탭을 참조한다. 자기 참조와 순환은 금지한다.
- 사건 하나가 여러 국가·카테고리에 연결되므로 숨김 `사건_국가(사건ID, 국가ID, 역할)`와 `사건_카테고리(사건ID, 카테고리ID)`에서 다대다 관계를 관리한다. 각각 505행·191행이다. 각 조합은 중복될 수 없으며 외래 키는 실제 원본 행을 가리켜야 한다.
- 사건 탭의 국가·카테고리 열은 연결표에서 이름을 찾아 표시하는 수식이다. 연결을 고칠 때는 연결표의 숨김을 해제해 ID를 편집한다. 이 두 열을 수동으로 덮어쓰지 않는다.

167개 사건 모두 관련 국가를 연결했다. 국가 탭의 75개 항목은 국가 63개, 정부 수립 전 지역 등 영토 3개, 조직 9개다. 동서독·남북베트남·정부 수립 이전 지역을 구별하고, 조약은 당시 서명국을 연결했다. 개최국이라는 이유만으로 회담 참가국에 포함하지 않는다. 관계는 사건과의 관련성을 나타내며 각국의 참전·가입 날짜를 대신하지 않는다. 사건의 원문·날짜·검토 상태는 유지했다.

## 이미지는 사건의 열에 저장

사건 탭의 **이미지** 열에 사진 주소를 넣는다. 사진이 여러 장이면 셀 안에서 줄바꿈으로 구별하며 위에서 아래 순서로 표시한다. 별도 사진 탭은 없다. 사진 20장은 19개 사건에 들어 있다. 기존 사진 파일과 앱의 URL 대응은 유지했다.

## 내용을 보존하는 규칙

- 사건명·본문·날짜·분류·국가 역할·지도자 표기·재임 기간·사진 순서를 보존한다. 미 지도자·소 지도자 열은 원본 표기이며 당시 재임 또는 실제 참여를 뜻하지 않는다.
- 날짜는 `1962`, `1962-10`, `1962-10-22`를 일반 텍스트로 저장한다. 모르는 월·일을 채우지 않는다. 기간의 시작·종료일은 모두 포함한다.
- 사건 종료일 공란은 한 시점의 사건이다. 재임·직위 종료일 공란은 확인 시점까지 이어짐을 뜻하며, 종료를 모르는 기간을 확정된 사실로 만들지 않는다.
- 재임의 교체일·겸직·직위명 변경을 지우거나 한 사람으로 단정하지 않는다. 직위 구분과 존재 기간은 재임기간 탭의 보조 열에 보존했다.
- 게임·날짜의 불확실성에 필요한 날짜유형·게임출제·검토상태는 보조 열에 보존했다. 검토 완료·출제 선택·날짜유형 stated인 사건만 게임에 쓰며 날짜 범위가 겹치거나 같은 날인 사건끼리는 선후를 채점하지 않는다.

출처·인용·원본 URL·수집 기록·이미지 관리 ID·이용 조건 열, 미해결 URL, 중복 원본 보관, 안내용 탭, 빈 확장 탭은 제거했다. 원본 보관의 텍스트는 사건 설명과 대조해 같음을 확인했다. 변경 전 사본은 로컬에 보관했다.

## 앱 출력

숨김 `web_feed`는 네 기본 탭과 두 연결표를 모으며 기존 게시 주소를 유지한다. 앱은 ID·날짜·외래 키·분류 순환·재임·사진 주소를 검증한 묶음만 반영한다. 잘못된 연결·빈 사건·읽기 실패 시 마지막 정상 데이터를 유지한다.

편집용 다섯 탭 외에 다대다 연결표 두 개와 앱 출력 하나가 숨겨져 있다. 공개 수식과 ID 선택 범위는 각 탭의 1000행까지이며 늘릴 때 함께 확장한다. 이전 상세 설계는 로컬 기록이며 현재 시트의 입력 명세는 이 문서다.
