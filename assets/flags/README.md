# 국가 식별용 국기

- `us/cn/tw/kr/kp/gb/fr/de/jp/cu.svg`: https://flagcdn.com/ 에서 받은 국가 식별용 SVG. 원본 공개 저장소 https://github.com/hampusborgos/country-flags (public domain).
- `ussr.webp`: https://assets.flagdb.com/v1/soviet-union/original-1600.webp
- `gdr.webp`: https://assets.flagdb.com/v1/east-germany/original-1600.webp
- FlagDB 다운로드 페이지는 자유 사용을 명시: https://www.flagdb.com/soviet-union/assets, https://www.flagdb.com/east-germany/assets

소련을 러시아 국기로, 동독을 현재 독일 국기로 대체하지 않는다. 동독의 문장 도입 전(1959년 10월 이전)은 삼색기를 쓴다. 미국 등의 국기는 국가 식별용이며 별 개수 등 모든 시기별 세부 변형을 재현하는 자료는 아니다.
